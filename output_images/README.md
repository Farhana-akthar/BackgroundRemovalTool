# Background Removal Tool

## Project Overview
This is a **Background Removal Tool** developed using **Python** and **OpenCV**. The project takes an input image, detects the main object (foreground), and removes or replaces the background. This tool can be used for **profile pictures, product images, e-commerce, ID photos**, and other applications where a clean background is required.

---

## Features
- Remove background from images using **GrabCut algorithm**
- Replace background with **white, custom image, or blur**
- Easy-to-use Python implementation
- Real-time preview using OpenCV image window

---

## Tools & Technologies
- **Language:** Python 3.x  
- **Libraries:** OpenCV, NumPy, Matplotlib  
- **IDE:** VS Code
